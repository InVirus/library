# Система управління бібліотекою

Цей проект — це веб-додаток для зручного керування бібліотекою. Він дозволяє адміністраторам додавати книги та вести облік клієнтів, а читачам — переглядати каталог і самостійно брати книги для читання.

🔗 **Сайт:** [https://libraryy.infinityfreeapp.com](https://libraryy.infinityfreeapp.com)


## Технології
- **Frontend:** React (Vite)
- **Backend:** PHP 
- **База даних:** MySQL

## Як запустити на своєму комп'ютері?

Щоб запустити цей проект локально, вам знадобиться `Node.js`.

1. Відкрийте папку проекту в терміналі.
2. Встановіть всі необхідні бібліотеки командою:
   ```bash
   npm install
   ```
3. Запустіть програму командою:
   ```bash
   npm run dev
   ```

*(Детальна технічна інформація описана у файлі `PROJECT_DOCS.md`)*
